# OSINT Atlas

Русскоязычный атлас открытого исследования: каталог источников с датами тестов, интерактивные маршруты, метаданные файлов, Google-дорки, карты, QR, расчёт солнца и God’s Eye View.

## Windows: готовый Atlas.exe

Скачайте `Atlas-Windows-x64.zip` из Releases, распакуйте и запустите `Atlas.exe`. Node.js и установка приложения не нужны. Все файлы интерфейса и глобуса встроены в EXE. Откроется браузер с локальным Atlas; окно запуска должно оставаться открытым. Закройте его или нажмите Ctrl+C, чтобы остановить сервер.

Приложение слушает только `127.0.0.1`, по умолчанию порт 4173. Если порт занят, выбирается свободный. Параметры: `Atlas.exe --no-open`, `Atlas.exe --port=4180`, `Atlas.exe --help`.

Целевая платформа: Windows 10/11 x64. EXE не подписан сертификатом издателя. Он не устанавливает службы, не добавляется в автозагрузку и не требует прав администратора.

## Что доступно без интернета

Интерфейс каталога, локальные фильтры и избранное, сборщик дорков, чтение метаданных, распознавание QR и расчёт солнца. Открытие внешних источников, поиск Google/Яндекс, подложки карт и данные глобуса требуют интернета. Базы людей, утечки, приватные источники и платные API не включены. Ключи не поставляются. GPS, файлы и QR обрабатываются браузером без загрузки на сервер Atlas.

## Запуск исходников

Нужен Node.js 24.22.1 x64 (или более новая версия ветки 24). Из каталога проекта:

```sh
node build.mjs
node server.mjs
```

Откройте `http://127.0.0.1:4173/#catalog`. Можно запускать `node server.mjs --open` на Windows. `PORT=4180` задаёт другой порт. Сам запуск исходников не требует установки пакетов: готовый God’s Eye View включён в `vendor-build/gods-eye`.

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm check
corepack pnpm test
corepack pnpm build:exe
```

Пересборка EXE выполняется на Windows x64 с Node.js 24.22.1 и создаёт `release/Atlas.exe`. Сборщик использует официальные Node SEA и postject. Зависимости esbuild/postject зафиксированы в `pnpm-lock.yaml`. Копирование Node.js в EXE сохраняет необходимость поставлять `NODE-LICENSE.txt`.

## GitHub Actions и серверный хостинг

Workflow `Build Atlas` проверяет исходники на Linux и Windows и собирает EXE на Windows. Артефакты скачиваются со страницы запуска Actions. По тегу `v*` исходный ZIP и Windows ZIP прикрепляются к GitHub Release. Workflow не разворачивает приложение публично и не передаёт пользовательские файлы внешним сервисам.

`dist/client` и `dist/server` — сборка для серверного хостинга. Для Cloudflare Workers используйте `dist/server/wrangler.json` и назначьте свой аккаунт/проект. Служебные идентификаторы прежнего хостинга исключены. **GitHub Pages не поддерживает серверный API глобуса**; полный Atlas требует Node.js или Worker, поэтому workflow Pages не включён.

## Структура

- `web/`: интерфейс и локальные инструменты; `editorial.css` / `editorial.js`: новая главная и схема источников.
- `worker/`: адаптеры фиксированных публичных источников глобуса, без произвольного проксирования URL.
- `desktop/`: сервер на loopback и точка входа EXE; `scripts/build-exe.mjs`: сборка одного файла.
- `apps/gods-eye/`: исходники приложения Bilawal Sidhu из предоставленного архива; `vendor-build/`: соответствующая готовая сборка.
- `integrations/`: зафиксированные зависимости локальных инструментов; `web/vendor/`: runtime-файлы и лицензии.
- `fixtures/`: синтетические тестовые файлы, не пользовательские документы.

Для пересборки God’s Eye View: установите его зависимости по `apps/gods-eye/pnpm-lock.yaml`, выполните `node node_modules/vite/bin/vite.js build --base=/gods-eye/`, перенесите результат в `vendor-build/gods-eye`, затем запустите корневую сборку.

## Методология, приватность и ограничения

Каталог содержит 20 ресурсов с конкретным публичным результатом теста от 03.11.2026; 19 кандидатов находятся в журнале. Это не гарантия всех функций или будущей доступности. У каждого ресурса указаны тест и ограничения; через 30 дней появляется отметка о перепроверке. Автоматического мониторинга нет. Даты меняют только после нового теста.

Избранное и тема хранятся в localStorage браузера. Поисковая строка каталога находится в URL. Отдельной регистрации и базы аккаунтов нет; обязательное принятие политики конфиденциальности не реализовано. Для самостоятельного публичного развёртывания нужны сведения об операторе и соответствующая опубликованная политика. Метаданные и QR могут быть изменены, а расчёт тени сам по себе не доказывает дату съёмки.

AI-голос, AIS, Google 3D, NASA FIRMS и отдельные камеры/погодные источники не подключены. Доступность публичных API и тайлов зависит от сети, региона и лимитов. Положение спутников рассчитывается из TLE. Исходное приложение глобуса сохраняет собственный интерфейс и уведомления об источниках.
